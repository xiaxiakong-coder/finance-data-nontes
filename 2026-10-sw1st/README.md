# 申万行业月度涨跌预测：简单量化模型与滚动验证

### 1.分析标的

申万一级行业指数（31个）

用每个月的月度特征，预测下个月行业指数收益方向，并检验这种预测力在样本外是否稳定。

*本报告在计算和建模方法上有一定局限性，其主要目的是用于作者个人学习阶段性总结和实践（数据获取、数据处理与清洗、简单ML方法应用），不构成任何实际投资建议。*

### 2.需要的数据

申万一级行业指数（31个），日线（2021.12-2026.10）

沪深300日线（2021.12-2026.10）

包括date, close, amount

检查各行业日线数据的空值与异常值；确认每个行业在每个月有完整交易日；

### 3.模型训练

| 特征 | 维度 | 一句话 |
| --- | --- | --- |
| `ret_1m` | 动量 | 当月涨跌 |
| `vol_1m` | 风险 | 当月波动大小 |
| `amt_chg` | 资金 | 成交额环比变化 |
| `corr_hs300` | 市场关联 | 跟大盘程度 |
| `ret_lag1` | 滞后动量 | 上月涨跌 |
| `skew_1m` | 分布形态 | 涨跌不对称性 |

对每个行业、每个月：

- `ret_1m`：月末收盘 / 月初收盘 - 1
- `vol_1m`：当月日收益率标准差
- `amt_chg`：当月日均成交额 / 上月日均成交额 - 1
- `corr_hs300`：当月行业日收益率与沪深300日收益率相关系数
- `ret_lag1`：上月的 `ret_1m`
- `skew_1m`：当月日收益率偏度

使用模型：高斯朴素贝叶斯分类

*使用朴素贝叶斯只是因为在目前所学的知识里，二分类方法相对来说更适合这个案例，并不是因为它是最佳选择。高斯朴素贝叶斯假设特征条件独立，而本报告的特征存在相关性，概率估计可能偏极端，仅用于排序分组。*

计算顺序

1. 原始日线 df：加 `month`，按行业算 `daily_ret`。
2. 从原始 df 按月聚合，算出 `ret_1m`、`vol_1m`、`amt_chg`、`skew_1m`，得到一个月频中间表。
3. 沪深300 日线单独算 `daily_ret`，按月分组，和行业日收益率对齐，算 `corr_hs300`，合并进月频表。
4. 在月频表上按行业 `shift`，算 `ret_lag1` 和 `label_next_month`。
5. 最终 `features_data` 就是滚动循环的输入。

### 4.操作步骤

- 涨是1，不涨（包括跌）是0，每次测试得到31个行业指数的上涨可能性分数（比如0.6）
- 每个测试月，按概率排序，取**前10个为高分组，后10个为低分组**。计算高分组下月平均收益率，计算低分组下月平均收益率，计算收益差
- 一共训练并测试33次，看收益差为正的次数为多少，如果<17次，说明模型可信度较低，如果>25次，说明模型有一定参考价值

    def train_test(start_month, end_month):
    
        Xtrain_1st = features_data[
            (features_data['month']>(pd.Period(start_month)-1)) & 
            (features_data['month']<pd.Period(end_month))
             ][['vol_1m', 'skew_1m', 'ret_1m', 'amt_chg', 'ret_lag1', 'corr_hs300']].copy().reset_index(drop=True)
    
        ytrain_1st = features_data[
            (features_data['month']>pd.Period(start_month)-1) & 
            (features_data['month']<pd.Period(end_month))
             ]['label_next_month'].copy().reset_index(drop=True)
    
        model = GaussianNB()
        model.fit(Xtrain_1st, ytrain_1st)
    
        Xtest_1st = features_data[
            (features_data['month']==pd.Period(end_month)) 
             ][['vol_1m', 'skew_1m', 'ret_1m', 'amt_chg', 'ret_lag1', 'corr_hs300']].copy().reset_index(drop=True)
    
        ytest_1st = features_data[
            features_data['month']==pd.Period(end_month)
             ]['ret_next_month'].copy().reset_index(drop=True)
    
        proba = model.predict_proba(Xtest_1st)[:,1]
    
        i = np.argsort(proba)
        high_i = i[-10:]
        low_i = i[:10]
        diff = ytest_1st[high_i].mean()-ytest_1st[low_i].mean()
        return diff

### 5.报告结果

- 在33次测试结果中，平均收益差为正的次数是9次，说明该模型可信度较低，没有预测力。
- **平均收益差和标准差**：平均收益差为 -1.39%，标准差为 3.19%，中位数为 -1.26%。
- **反向信号的现象**：值得注意的是，将高低分组对调后，低分组在24/33个月中跑赢高分组，平均收益差+1.39%。该反向信号在样本期内具有一定一致性，但受限于样本长度、未扣交易成本、未做分年度稳定性检验，不宜直接作为投资依据。

### 6.局限性总结

- 采用样本数较少，不足以构成训练和测试的素材，结论包含的噪声极可能大于有效信息；
- 样本外测试月仅33个，且滚动窗口高度重叠，33次测试并非独立样本，方向一致性的统计显著性有限；
- 未考虑交易成本、滑点、行业指数不可直接交易等实盘约束，收益差为理论值；
- 模型未做特征正交化处理，朴素贝叶斯的条件独立假设不成立，概率估计可能偏极端。

### 7.学习总结

- 在数据获取后进行了空值和异常值的排查；
- 学会用pct_change方法进行收益率的计算；
- 学会用shift方法进行错位记录；
- 用函数方法批量输入和输出样本；
- 使用了时序滚动方法；
- 实践了数据获取、数据处理、特征构造、模型训练与测试、结论分析的全流程；
- 理解了时序滚动验证中训练集与测试集的边界划分，以及如何避免未来函数；
- 认识到金融数据信噪比低，简单模型在短样本、短测试期下容易失效甚至反向，样本外验证是必要的。
